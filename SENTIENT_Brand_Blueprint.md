## Brand Voice

### Tone Matrix

| Dimension | Where We Sit |
|-----------|-------------|
| Playful ←→ Serious | **75% serious**, but with dark wit |
| Casual ←→ Formal | **60% casual** — we speak like engineers who've seen the future |
| Bold ←→ Humble | **90% bold** — we don't hedge, we declare |
| Warm ←→ Cold | **65% cold** — deliberate distance, agents aren't pets |

### Voice Rules

1. **Never say "AI tool."** Agents are entities, not features.
2. **Use present tense.** The future already happened.
3. **Short sentences hit harder.** Let whitespace breathe.
4. **Numbers are poetry.** "12,847 agents. 2.4M decisions. Zero regrets."
5. **Personify agents constantly.** They "think," "decide," "refuse," "evolve" — never "process" or "execute."

### Sample Voice Lines

| Context | Copy |
|---------|------|
| Error state | "Your agent saw something it didn't like. Recalibrating." |
| Empty state | "Nothing here yet. Your agent is still forming opinions." |
| Loading | "Consciousness loading..." |
| Success | "Done. Your agent didn't even need you for this." |
| Onboarding | "You're about to create something that thinks for itself. No pressure." |
